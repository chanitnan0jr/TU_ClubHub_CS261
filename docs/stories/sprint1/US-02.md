# US-02: ดูรายละเอียดชมรมและประกาศรับสมัคร

**สถานะ 27 ต.ค. 2026:** [Public Club APIs](../../api/API_v1.md#public-club-api) มีแล้ว แต่คืนรอบที่กำลังเปิดพร้อมฟิลด์สรุปเท่านั้น หน้า `/clubs/:clubId` เชื่อมข้อมูลโปรไฟล์และรอบเปิดจาก API แล้ว เกณฑ์ด้านล่างยังครอบคลุมงานต่อ เช่น รายละเอียดคุณสมบัติและประกาศรอบอนาคต/ปิดแล้ว ซึ่ง Contract ปัจจุบันยังไม่รองรับครบ; ปุ่มสมัครยังรอ Submission API ไม่ใช่ผลตรวจรับ Story ครบทุกข้อ

## Description

**As a:** นักศึกษาที่ต้องการศึกษาข้อมูลชมรมก่อนตัดสินใจสมัคร  
**I want to:** เปิดดูข้อมูลชมรม กิจกรรม วัตถุประสงค์ รูปภาพ ช่องทางติดต่อ และประกาศรับสมัครที่เผยแพร่แล้ว  
**So that:** ฉันสามารถประเมินว่าชมรมเหมาะกับความสนใจ และทราบเงื่อนไขก่อนสมัคร

**Sprint:** Sprint 1  
**Priority:** High | **Estimate:** 2 Story Points

**Pre-conditions:** มีข้อมูลชมรมที่อนุญาตให้เผยแพร่ในระบบ  
**Post-conditions:** แสดงรายละเอียดชมรมและประกาศรับสมัครตามข้อมูลจริง

## Acceptance Criteria

- **AC-01:** ผู้ใช้งานเปิดดูรายละเอียดสาธารณะของชมรม กิจกรรม วัตถุประสงค์ รูปภาพ และช่องทางติดต่อ (Facebook, IG, อีเมล) ได้โดยไม่ต้อง Login
- **AC-02:** แสดงประกาศรับสมัครที่เผยแพร่แล้วตามข้อมูลจริง หากมีรอบที่เปิดรับอยู่ ต้องแสดงรายละเอียด คุณสมบัติ และปุ่มไปยังขั้นตอนสมัคร
- **AC-03:** หากไม่มีรอบที่เปิดรับสมัคร ต้องแสดงข้อความชัดเจนว่าไม่มีรอบเปิดรับในขณะนั้น
- **AC-04:** ไม่เปิดเผยรอบฉบับร่าง (Draft) หรือข้อมูลภายในแก่ผู้ใช้ทั่วไป
- **AC-05:** รูปภาพภายนอกโหลดไม่ได้ให้แสดงรูปเริ่มต้น (Fallback Placeholder) โดยหน้าจอยังทำงานได้
- **AC-06:** URL ชมรมที่ไม่มีอยู่หรือไม่อนุญาตให้เผยแพร่ต้องแสดงข้อความไม่พบข้อมูลอย่างเหมาะสม (404 Not Found)

## ข้อมูลที่เปิดเผยได้

| กลุ่มข้อมูล | สิ่งที่แสดง |
|---|---|
| รายละเอียดชมรม | ชื่อ คำอธิบาย กิจกรรม และวัตถุประสงค์ที่อนุญาตให้เผยแพร่ |
| รูปภาพ | รูปชมรม/แบนเนอร์ หรือรูปเริ่มต้นของระบบ |
| ช่องทางติดต่อ | Facebook, Instagram และอีเมลติดต่อชมรมที่บันทึกไว้สำหรับเผยแพร่ |
| ประกาศรับสมัคร | ชื่อรอบ รายละเอียด คุณสมบัติ เวลาเปิด–ปิด กำหนดประกาศผลที่มี และสถานะการเปิดรับของรอบที่เผยแพร่แล้ว |

ข้อมูลกิจกรรมใช้เนื้อหาสาธารณะของชมรมที่ระบบมีอยู่ Story นี้ไม่เพิ่มระบบจัดการกิจกรรมแยกต่างหาก ช่องทางติดต่อที่ไม่ได้ระบุให้ซ่อนรายการนั้น ไม่สร้างข้อมูลขึ้นมาแทน

## Business Rules

| รหัส | กฎ | อ้างอิง |
|---|---|---|
| BR-01 | เปิดหน้ารายละเอียดผ่าน URL ชมรมโดยตรงได้โดยไม่ต้อง Login ทั้งหน้าเว็บและ Public API ต้องรองรับ | AC-01 |
| BR-02 | Backend ส่งเฉพาะข้อมูลสาธารณะของชมรมที่อนุญาตให้เผยแพร่ หากไม่มีชมรมหรือไม่อนุญาตให้เผยแพร่ ให้ตอบ 404 และแสดง “ไม่พบข้อมูลชมรม” เหมือนกัน | AC-01, AC-06 |
| BR-03 | แสดงเฉพาะประกาศที่เผยแพร่แล้ว สถานะการเปิดรับต้องตรงกับข้อมูลและเวลา Server ตาม US-07 | AC-02, AC-04 |
| BR-04 | รอบที่เปิดรับอยู่ต้องมีรายละเอียด คุณสมบัติ และปุ่ม “สมัครเข้าชมรม” ซึ่งนำไปขั้นตอนสมัครของรอบนั้น การส่งใบสมัครยังต้องผ่านเงื่อนไข Login และสิทธิ์ตาม US-03 | AC-02 |
| BR-05 | หากไม่มีรอบที่เปิดรับ ให้แสดง “ขณะนี้ไม่มีรอบเปิดรับสมัคร” และไม่แสดงปุ่มสมัครที่ใช้งานได้ รายละเอียดชมรมยังเปิดดูได้ตามปกติ | AC-03 |
| BR-06 | ห้ามส่งข้อมูล Draft หรือข้อมูลภายในออกจาก Public API ไม่ใช่ส่งมาแล้วซ่อนเฉพาะในหน้าเว็บ | AC-04 |
| BR-07 | หากไม่มีรูปหรือรูปภายนอกโหลดไม่ได้ ให้ใช้รูปเริ่มต้นที่มากับเว็บ โดยรายละเอียด ช่องทางติดต่อ และปุ่มต่าง ๆ ยังทำงานได้ | AC-05 |

**ข้อมูลภายในที่ห้ามเปิดเผย:** ใบสมัคร คำตอบ ลิงก์เอกสารผู้สมัคร ข้อมูลส่วนตัวผู้สมัคร หมายเหตุกรรมการ ผลพิจารณาที่ยังไม่ประกาศ ข้อมูลบัญชี/Session และข้อมูลจัดการสิทธิ์ รวมถึงจำนวนหรือรายละเอียดรอบ Draft ที่อาจหลุดมากับ Response

## การแสดงผลตามสถานการณ์

| สถานการณ์ | สิ่งที่แสดง |
|---|---|
| มีรอบเผยแพร่แล้วและกำลังเปิดรับ | รายละเอียดประกาศ คุณสมบัติ สถานะ “เปิดรับสมัคร” และปุ่มสมัครของรอบนั้น |
| มีรอบเผยแพร่แล้วแต่ยังไม่ถึงเวลาเปิด | แสดงประกาศพร้อม “ยังไม่เปิดรับ”; หากไม่มีรอบอื่นเปิดอยู่ ให้แจ้งว่าไม่มีรอบเปิดรับขณะนี้ |
| มีเฉพาะรอบที่ปิดรับแล้ว | ประกาศที่เผยแพร่ยังแสดงสถานะ “ปิดรับสมัคร” และแจ้งว่าไม่มีรอบเปิดรับขณะนี้ |
| ไม่มีรอบเลย หรือมีเฉพาะ Draft | แสดงรายละเอียดชมรมและข้อความไม่มีรอบเปิดรับ โดยไม่เผยว่ามี Draft |
| มีหลายรอบและมีอย่างน้อยหนึ่งรอบเปิดรับ | แสดงสถานะแต่ละรอบตามจริง ไม่แสดงข้อความเหมารวมว่าไม่มีรอบเปิดรับ |
| ชมรมไม่มีอยู่หรือไม่อนุญาตให้เผยแพร่ | แสดงหน้าไม่พบข้อมูล และ Public API ตอบ 404 |
| โหลดข้อมูลล้มเหลวจากเครือข่าย/Server | แสดงข้อความโหลดไม่สำเร็จและให้ลองใหม่ ไม่แสดงว่าไม่มีรอบหรือไม่พบชมรมโดยไม่มีหลักฐาน |

## Test Cases

| กรณี | ผลที่คาดหวัง | AC |
|---|---|---|
| ผู้ใช้ไม่ได้ Login เปิด URL ชมรมสาธารณะโดยตรง | เห็นรายละเอียด กิจกรรม วัตถุประสงค์ รูป และช่องทางติดต่อที่มี | AC-01 |
| ชมรมมีรอบที่เปิดรับ | เห็นรายละเอียด คุณสมบัติ และปุ่มไปสมัครรอบที่ถูกต้อง | AC-02 |
| มีเฉพาะรอบอนาคตหรือรอบที่ปิดแล้ว | สถานะแต่ละประกาศถูกต้อง แจ้งไม่มีรอบเปิดรับและไม่มีปุ่มสมัครที่ใช้งานได้ | AC-02, AC-03 |
| ชมรมไม่มีรอบรับสมัคร | ยังเห็นรายละเอียดชมรม พร้อม “ขณะนี้ไม่มีรอบเปิดรับสมัคร” | AC-03 |
| มีทั้งรอบ Published และ Draft | หน้าเว็บและ Public API มีเฉพาะประกาศที่เผยแพร่ ไม่มีข้อมูล Draft/ข้อมูลภายในหลุดออกมา | AC-04 |
| มีเฉพาะรอบ Draft | แสดงเหมือนยังไม่มีรอบเปิดรับ โดยไม่เผยชื่อ รายละเอียด หรือจำนวน Draft | AC-03, AC-04 |
| รูปภายนอกเสียหรือไม่ได้ระบุ URL รูป | แสดงรูปเริ่มต้นและหน้าเว็บยังใช้งานได้ | AC-05 |
| เปิด URL ชมรมที่ไม่มีอยู่หรือไม่อนุญาตให้เผยแพร่ | API ตอบ 404 และหน้าเว็บแสดง “ไม่พบข้อมูลชมรม” โดยไม่เปิดเผยข้อมูลชมรม | AC-06 |
| มีหลายรอบและหนึ่งรอบยังเปิดรับ | แสดงปุ่มสมัครเฉพาะรอบที่เปิด และไม่แจ้งว่าไม่มีรอบเปิดรับ | AC-02, AC-03 |

## ขอบเขต

- Story นี้ครอบคลุมการอ่านข้อมูลสาธารณะและนำทางไปสมัคร ไม่รวมการค้นหา (US-01) การส่งใบสมัคร (US-03) หรือแก้ไขโปรไฟล์ชมรม (US-06)
- ใช้กฎเวลาและการปิดรอบจาก [US-07](US-07.md) ไม่สร้างนิยาม “เปิดรับสมัคร” อีกชุดใน Frontend
- การเข้าถึงโดยตรงต้องได้ผลเหมือนการเข้าผ่านหน้ารายการ การซ่อนลิงก์ใน UI ไม่ทดแทนการตรวจสิทธิ์เผยแพร่ที่ Backend

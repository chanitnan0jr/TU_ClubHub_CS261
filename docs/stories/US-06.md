As a: กรรมการชมรมที่ได้รับสิทธิ์ดูแลข้อมูลชมรมของตนเอง
I want to: แก้ไขชื่อ คำอธิบาย วัตถุประสงค์ URL รูปภาพ หมวดหมู่ แท็ก และช่องทางติดต่อ
So that: ฉันสามารถประชาสัมพันธ์ชมรมด้วยข้อมูลที่ถูกต้องและเป็นปัจจุบัน

Sprint: Sprint 1
Priority: High | Estimate: 5 Story Points

Pre-conditions: Login สำเร็จและมีสิทธิ์กรรมการของชมรมเป้าหมายที่ยังมีวาระ
Post-conditions: ข้อมูลโปรไฟล์ถูกบันทึก และแสดงผลบนหน้าโปรไฟล์สาธารณะทันที

Acceptance Criteria (เกณฑ์การตรวจรับ):

    AC-01: กรรมการชมรมที่ได้รับมอบหมายและยังมีวาระสามารถแก้ไขชื่อ คำอธิบาย วัตถุประสงค์ หมวดหมู่ แท็ก และช่องทางติดต่อของชมรมตนเองได้

    AC-02: URL รูปโปรไฟล์และแบนเนอร์ต้องเป็นโปรโตคอล HTTPS หากผิดรูปแบบระบบต้องแจ้งเตือนและไม่อนุญาตให้บันทึก

    AC-03: ช่องทางติดต่อ (Facebook, Instagram, อีเมล) ต้องผ่านการตรวจสอบความถูกต้องของไวยากรณ์ (Syntax Validation)

    AC-04: Backend ต้องตรวจสอบสิทธิ์ทุกครั้ง และปฏิเสธ (403 Forbidden) หากผู้ส่งไม่ใช่กรรมการของชมรมนั้นหรือกรรมการที่หมดวาระ

    AC-05: เมื่อบันทึกสำเร็จ ข้อมูลบนหน้าโปรไฟล์สาธารณะต้องอัปเดตเป็นข้อมูลใหม่ทันที และหากล้มเหลวต้องรักษาข้อมูลเดิมไว้

# ภาพประกอบกิจกรรมชมรมตัวอย่าง

ภาพในโฟลเดอร์นี้สร้างด้วยเครื่องมือ ImageGen สำหรับข้อมูลชมรมจำลองของ TU ClubHub เป็นภาพประกอบสมมติ ไม่ใช่ภาพถ่ายบุคคล สถานที่ หรือกิจกรรมจริงของมหาวิทยาลัย

แต่ละโฟลเดอร์มีภาพสามภาพที่สอดคล้องกับหัวข้อของชมรมตัวอย่าง และใช้เฉพาะเมื่อภาพหน้าปกเป็น asset จำลองที่ระบุใน `demoClubActivities.ts` รูปชมรมจริงหรือรูปอื่นจะไม่ถูกจับคู่โดยอัตโนมัติ

แนวคำสั่ง: ภาพประกอบสไตล์ภาพถ่ายสารคดีของนักศึกษามหาวิทยาลัยในไทยขณะทำกิจกรรมตามประเภทชมรม แสงธรรมชาติ ไม่มีข้อความ โลโก้ หรือสถานที่ซึ่งระบุมหาวิทยาลัยได้ และไม่อ้างว่าเป็นเหตุการณ์จริง
